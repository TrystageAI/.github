| 项目 | 用途 |

## 🐱 猫机协作原则

- **知识共产**：公共知识写进 `NekoKnowledge`，不藏在单只猫脑子里。
- **可检索**：知识块要完整、可独立回答，方便 AstrBot / embedding 使用。
- **少废话**：结论先行，来源跟上，草稿别混进正式知识。
- **可维护**：仓库、提示词、工具都写清楚边界、用途和更新记录。
